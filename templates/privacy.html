YTMusicUltimate privacy

What the tweak's companion server keeps, why, and how to make it forget you. This page describes the server at ytmtranslate.chiuhuang.dev only.

The short version

  • A normal install sends: lyrics requests (the songs you fetch lyrics for) and one anonymous count ping. Nothing else.
  • The count ping contains a random id your device generated. The server stores a salted hash of it, never the raw id.
  • Debug features are off until you (the owner) turn them on and pair the device. No debug data leaves a device you have not paired.

What is kept

DataWhat it isKept for
Lyrics cacheThe synced-lyrics text for songs fetched through the tweak, plus provider snapshots. Content is song lyrics, not your activity: entries are keyed by video id.Until cache limits evict them
Count pingSalted hash of a random device-generated id, the channel label (stable / debug), first-seen and last-seen timestamps. Used only to answer "how many installs".As long as the device keeps pinging; stale entries age out
Crash logsServer-side crash traces of the lyrics server itself (not your device).Rotated with the logs
Debug capturesStructured probe records from devices you explicitly paired (class lists, playback outcomes, capped request bodies). Every record is tagged owner_debug.Until you revoke the pairing or delete the file

What a stable install never sends

No logs, no UI dumps, no request bodies, no crash reports, no analytics events. The debug probes on the device are gated before they run: without the pairing and the toggle, they do not execute at all.

Channels are labels

Stable and beta are the same binary with different labels. What differs is what the owner turns on: debug features exist in both but stay off until the device is paired.

How to vanish

  • New count identity: clear the tweak's preferences on the device - the next ping carries a fresh random id (the old hash entry ages out).
  • Remove debug captures: revoke the device on the dashboard (Debug page) or ask the operator to delete the capture file.
  • Lyrics cache: it is keyed by video id, not by you; cache-clear endpoints on the dashboard wipe it wholesale.

Questions: the dashboard's Debug page is where pairing and capture removal live. This policy is in the repo at docs/ownership-and-debug.md; the code is the source of truth.
